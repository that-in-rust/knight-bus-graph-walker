## Primary-Source Premise Verification

Verified 2026-09-19: [Neo4j GDS feature toggles](https://neo4j.com/docs/graph-data-science/current/production-deployment/feature-toggles/) explicitly documents CSR and default variable-length/delta-compressed adjacency. Packed integer adjacency is an alternative off-heap layout; its memory must also be budgeted. Thus the claim that GDS universally uses per-edge pointer objects is false. A fair baseline must pin version, representation, projection properties, ID mapping and concurrency. The page also names projection costs beyond compression. This is primary documentation evidence, not a local GDS benchmark.

[GridGraph, USENIX ATC 2015](https://www.usenix.org/conference/atc15/technical-session/presentation/zhu) already uses 1D vertex chunks, 2D edge blocks, dual sliding windows and selective scheduling. Tiling plus active-block skipping cannot be claimed as a new invention here. Candidate advances must improve state traffic, semantics-aware skipping or build/refresh amortization beyond that baseline.
